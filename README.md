# Sabbir Calculator Pro

A mobile-first, offline-capable scientific calculator web app.

## Run
Open `index.html` in a modern browser. For install/offline support, serve this folder over HTTPS (for example GitHub Pages), open it in Chrome on Android, then choose **Add to Home screen / Install app**.

## Features
- Arithmetic, brackets, percentage, powers, factorial
- sin/cos/tan (DEG/RAD), log, ln, square root
- π, e, previous answer
- Calculation history
- Dark/light appearance
- Offline cache after first visit

This is a PWA source project, not a compiled Android APK. A native APK requires an Android build environment.
